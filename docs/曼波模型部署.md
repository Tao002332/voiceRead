# 曼波音色部署（本地 GPT-SoVITS 服务）

本工具的「曼波本地语音」不是内置模型，而是对接一个**本机运行的 GPT-SoVITS 语音服务**。
原因：曼波是社区训练的音色模型，绝大多数发布形式都是 GPT-SoVITS 的 `.pth` 权重，
用独立服务托管最稳，也不会拖慢朗读主程序。

---

## 0. 环境要求

| 项 | 要求 |
|---|---|
| 显卡 | NVIDIA，≥ 6GB 显存（RTX 3060 Laptop 6GB 即可跑，但句子要短） |
| 内存 | ≥ 16GB |
| 磁盘 | 模型 + 环境 8–12GB |
| 系统 | Windows 10/11 x64 |

显存 6GB 的关键设置：`is_half=True`（半精度）、`batch_size=1`、句子切短。

---

## 1. 装 GPT-SoVITS

两种路子，选一种：

**A. 整合包（推荐，省事）**
1. 下载 GPT-SoVITS 整合包（B 站「花儿不哭」官方整合包 v2 / v3，解压即用，自带 python 和 torch）
2. 解压到无空格、无中文的路径，例如 `D:\GPT-SoVITS`
3. 双击 `go-webui.bat` 能出网页界面，说明环境 OK，关掉

**B. 源码安装**
```powershell
git clone https://github.com/RVC-Boss/GPT-SoVITS.git D:\GPT-SoVITS
cd D:\GPT-SoVITS
# 在整合包/官方文档指定的 python 3.10 环境里
pip install -r requirements.txt
```
> torch 版本要和显卡驱动匹配；整合包已经把这一步做完了，自己装容易踩坑。

---

## 2. 放曼波模型

曼波模型一般由发布者提供两个文件：

- `xxx.ckpt`  —— GPT 部分
- `xxx.pth`   —— SoVITS 部分
- 可能还有一个 `参考音频.wav` + `参考文本.txt`

放置方式（GPT-SoVITS v2 结构）：

```
D:\GPT-SoVITS\
├─ GPT_SoVITS\
│  ├─ pretrained_models\
│  │  ├─ gpt\        ← .ckpt 放这里
│  │  └─ sovits\     ← .pth  放这里
│  └─ configs\
│     └─ tts_infer.yaml   ← 在这里把路径指到上面两个文件
```

`tts_infer.yaml` 关键字段：

```yaml
v2:
  bert_base_path: GPT_SoVITS/pretrained_models/chinese-roberta-wwm-ext-large
  cnhuhbert_base_path: GPT_SoVITS/pretrained_models/chinese-hubert-base
  device: cuda
  is_half: true
  t2s_weights_path: GPT_SoVITS/pretrained_models/gpt/曼波.ckpt
  vits_weights_path: GPT_SoVITS/pretrained_models/sovits/曼波.pth
```

> 不同整合包版本目录名可能略有差异，以包内说明为准；核心就一句：
> **让 `t2s_weights_path` 指向 ckpt、`vits_weights_path` 指向 pth。**

`is_half` 在 6GB 卡上必须是 `true`，否则容易 OOM。

---

## 3. 准备参考音频（决定「像不像曼波」）

参考音频是音色的关键，比模型本身还影响听感：

| 要求 | 说明 |
|---|---|
| 时长 | 3–10 秒（5 秒左右最稳） |
| 内容 | 单人、无背景音乐、无环境噪音 |
| 格式 | wav，24kHz 或 32kHz，单声道 |
| 参考文本 | **必须和音频里说的每个字完全一致**，标点也要对得上 |

把音频放好，例如 `D:\GPT-SoVITS\refs\mambo_ref.wav`，参考文本例：
`曼波，我们走，今天也要开开心心的。`

> 想要多种「曼波」质感（平静 / 激动 / 低沉），就准备多段参考音频，
> 在工具里做成多个音色预设，切换预设即切换音色，不用重启服务。

---

## 4. 启动服务

在 GPT-SoVITS 目录下：

```powershell
# 整合包自带的 python
.\runtime\python.exe api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS/configs/tts_infer.yaml
```

看到 `TTS server listening on 127.0.0.1:9880` 就成了。
服务只要开着，工具就能用；**关掉服务后工具会自动报错提示**，不会卡死。

验证（浏览器打开）：
```
http://127.0.0.1:9880/tts?text=你好&text_lang=zh&ref_audio_path=E:/GPT-SoVITS/refs/mambo_ref.wav&prompt_text=参考文本&prompt_lang=zh
```
返回一段 wav 就通了。

---

## 5. 在工具里配置

设置 → 语音引擎 → 选「曼波本地语音」：

| 字段 | 填法 |
|---|---|
| 服务地址 | `http://127.0.0.1:9880` |
| 音色预设 | 点「新增音色」可建多个 |
| 预设名称 | 曼波（或「曼波-激动」之类） |
| 参考音频 | 上面那段的 wav 绝对路径 |
| 参考文本 | 与音频一字不差的文本 |
| 启动命令 | 可选。填了并勾「自动拉起」，启动工具时自动开服务 |
| 测试连接 | 点一下，状态会告诉我们具体卡在哪 |

启动命令示例：
```
D:\GPT-SoVITS\runtime\python.exe D:\GPT-SoVITS\api_v2.py -a 127.0.0.1 -p 9880 -c D:\GPT-SoVITS\GPT_SoVITS\configs\tts_infer.yaml
```

配好后点「试听当前音色」，能听到就算通了，再回主界面朗读。

---

## 6. 排错

| 现象 | 原因 / 处理 |
|---|---|
| 测试连接：连不上 | 服务没起、端口被占。先手动跑 api_v2.py 看报错 |
| 返回 400 / 500 | 参考音频路径含中文或空格；改用纯英文路径 |
| 音频是空的 | 参考文本和音频对不上，或模型与参考音频版本不匹配 |
| 声音像念稿、不像曼波 | 参考音频质量不行（有 BGM / 太长 / 情绪不对），换一段 |
| CUDA out of memory | `is_half: true`、句子切短（工具已按 60–90 字切句）、关掉其他占显存的程序 |
| 首句特别慢 | 模型加载 + 首次推理，正常；后续句子走缓存 |
| 读错多音字 | 曼波模型自身问题，可在书里手动改字，或换 Edge 引擎对照 |

## 8. 本机实际部署（已执行，2026 年）

> 这一节记录本机真实落地的路径与结论，和上面「通用教程」略有不同，以本节为准。

### 8.1 结论：不需要单独的「曼波 .pth」

公开渠道（HuggingFace / ModelScope）**没有**可直接下载的曼波 GPT-SoVITS 权重。
经查证，社区做法是 **GPT-SoVITS 零样本克隆**：拿一段曼波的原声（3–10 秒），
配合官方 v2 底模，就能克隆出曼波音色。所以「曼波模型文件」= 底模 + 一段参考音频。

- 底模：`lj1995/GPT-SoVITS` 官方 v2 预训练（已下）
- 音色：`models/refer.wav`（32kHz / 单声道 / 约 4 秒，来自 MamboTTS 项目）

### 8.2 已落地的目录

```
<项目目录>\mambo\
├─ GPT-SoVITS\                       官方源码（main 分支）
│  └─ GPT_SoVITS\pretrained_models\
│     ├─ chinese-hubert-base\                    180 MB
│     ├─ chinese-roberta-wwm-ext-large\          621 MB
│     └─ gsv-v2final-pretrained\
│        ├─ s1bert25hz-5kh-longer-epoch=12-step=369668.ckpt   148 MB
│        ├─ s2G2333k.pth                          101 MB
│        └─ s2D2333k.pth                           89 MB
├─ refs\mambo_ref.wav                曼波参考音频（音色来源）
└─ venv\                             torch(cu121) + GPT-SoVITS 依赖
```

模型合计约 1.14 GB（不含 torch）。

### 8.3 三段命令

```powershell
# ① 一键装环境（源码+模型+torch+依赖，可重复执行，已下载的会跳过）
powershell -ExecutionPolicy Bypass -File scripts\setup_mambo_win.ps1

# ② 起服务（保持窗口开着）
powershell -ExecutionPolicy Bypass -File scripts\start_mambo_server.ps1

# ③ 联调自测（另开一个窗口）
.\.venv\Scripts\python.exe scripts\test_mambo_tts.py
```

或直接双击 `启动曼波服务.bat`。

### 8.4 关键配置

`GPT_SoVITS/configs/tts_infer.yaml` 的 `custom` 段（api_v2 实际读这一段）：

```yaml
custom:
  bert_base_path: GPT_SoVITS/pretrained_models/chinese-roberta-wwm-ext-large
  cnhuhbert_base_path: GPT_SoVITS/pretrained_models/chinese-hubert-base
  device: cuda
  is_half: true
  t2s_weights_path: GPT_SoVITS/pretrained_models/gsv-v2final-pretrained/s1bert25hz-5kh-longer-epoch=12-step=369668.ckpt
  version: v2
  vits_weights_path: GPT_SoVITS/pretrained_models/gsv-v2final-pretrained/s2G2333k.pth
```

### 8.5 工具里的对应设置

设置 → 语音引擎 → 曼波本地语音：

| 字段 | 值 |
|---|---|
| 服务地址 | `http://127.0.0.1:9880` |
| 参考音频 | `<项目目录>\mambo\refs\mambo_ref.wav`（工具已自动填入） |
| 参考文本 | 留空即可（零样本模式，音色由音频决定） |
| 启动命令 | `<项目目录>\mambo\venv\Scripts\python.exe <项目目录>\mambo\GPT-SoVITS\api_v2.py -a 127.0.0.1 -p 9880 -c <项目目录>\mambo\GPT-SoVITS\GPT_SoVITS\configs\tts_infer.yaml` |

### 8.6 想更「像」曼波怎么办

参考音频决定音色上限，优先级：

1. **换参考音频**（最有效）：找 3–10 秒、无 BGM、情绪贴合的原声，替换 `mambo_ref.wav`，在设置里新增一个预设即可
2. 开多预设：平静 / 激动 / 低沉各一段，朗读时按书切换
3. 训练专属 LoRA：官方 `GPT_SoVITS` 支持微调，需要 1 小时以上素材 + 3090 级别显存，本机 6GB 不建议
