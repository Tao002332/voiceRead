# 打包与分发

目标：把工具拷到**没有 Python 环境**的 Windows 电脑上，双击就能用。

---

## 1. 产物是什么

`packaging\build.ps1` 用 PyInstaller 打成 **onedir**（免安装目录）：

```
dist\语音书架\
├─ 语音书架.exe          ← 双击这个
├─ _internal\            ← 依赖（Python 运行时 + PySide6 等，约 250MB）
└─ ...
```

**为什么不用 onefile**：onefile 每次启动都要把 200MB+ 解压到临时目录，冷启动 5–10 秒，
而且字幕窗/托盘这类常驻窗口的杀软误报率更高。onedir 启动 1 秒内。

## 2. 目标机要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 x64 |
| Python | **不需要**，已打进包里 |
| 网络 | 用 Edge 在线语音时需要；纯离线可用 Windows SAPI |
| 显卡 | 只有用曼波本地语音时才需要 NVIDIA（≥6GB 显存） |
| 权限 | 普通用户即可，数据写在 `%APPDATA%\VoiceRead` |

## 3. 直接可用的功能

拷贝整个 `dist\语音书架` 目录到目标机任意位置（**建议全英文路径**），双击 `语音书架.exe`：

- ✅ 书架 / 导入 TXT+EPUB / 分章 / 断点续读
- ✅ 悬浮字幕（置顶、可拖、6 个控制按钮、右键菜单）
- ✅ **Edge 在线语音**（默认，免费，10 个中文音色）
- ✅ **Windows SAPI 离线语音**（断网兜底）
- ✅ 语速/音调/停顿、上下文语调、分块连续播放
- ✅ 托盘、全局热键、缓存自动清理

首次启动如果检测不到曼波环境，会**自动退回 Edge 语音**，不会报错卡住。

## 4. 把曼波音色也带过去

曼波 = GPT-SoVITS 服务 + torch(cu121) + 1.15GB 模型。**venv 不可跨机复制**（`pyvenv.cfg`
里写死了本机 Python 路径），所以有两条路：

### 方案 A：目标机重新安装（推荐，最稳）

把这几样东西一起拷过去（合计约 1.3GB）：

```
mambo\GPT-SoVITS\            ← 源码，约 200MB
mambo\GPT_SoVITS\pretrained_models\   ← 模型 1.15GB（在 GPT-SoVITS 目录内）
mambo\refs\                  ← 参考音频 + prompt_text.txt
scripts\setup_mambo_win.ps1
scripts\install_gsv_deps.ps1
scripts\patch_mambo_env.ps1
```

目标机上（需联网，会下 torch 约 2.5GB + 依赖）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup_mambo_win.ps1
powershell -ExecutionPolicy Bypass -File scripts\install_gsv_deps.ps1
powershell -ExecutionPolicy Bypass -File scripts\patch_mambo_env.ps1
```

> `setup_mambo_win.ps1` 会跳过已存在的模型文件，所以只补 torch 和依赖，比全量下载快。

然后启动服务并在工具里配置：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\start_mambo_server.ps1
```

设置 → 语音引擎 → 曼波本地语音 → 服务地址 `http://127.0.0.1:9880`，
参考音频选 `mambo\refs\mambo_ref_clean.wav`，点「测试连接」。

### 方案 B：整目录拷（仅限同款环境）

如果目标机与本机同为 Windows + 相同 Python 版本，可试：
拷贝整个 `mambo` 目录（含 venv），然后编辑 `mambo\venv\pyvenv.cfg`，
把 `home = ...` 改成目标机上的 Python 目录。**不保证成功**，仅作应急。

## 5. 生成分发包

```powershell
# 打包
powershell -ExecutionPolicy Bypass -File packaging\build.ps1

# 压缩成 zip（体积约 90–110MB）
Compress-Archive -Path 'dist\语音书架\*' -DestinationPath 'dist\语音书架-win64.zip' -Force
```

分发时把 `语音书架-win64.zip` 给对方即可；解压后双击 exe。

## 6. 数据位置

运行数据都在用户目录，不污染程序目录，**升级时直接覆盖程序文件即可，书架和进度不丢**：

```
%APPDATA%\VoiceRead\
├─ settings.json     设置
├─ library.json      书架索引
├─ books\            各书章节正文
├─ progress.json     每本书阅读进度
├─ cache\            音频缓存（按 10 分钟滚动清理）
└─ logs\             crash.log / settings.log
```

## 7. 常见问题

**双击没反应**：看 `%APPDATA%\VoiceRead\logs\crash.log`；也可能是杀软拦截了 PyInstaller 产物，
把程序目录加入白名单。

**Edge 语音报错**：需要联网；可在设置里切到「Windows 离线语音（SAPI）」临时顶替。

**曼波「服务未启动」**：先手动跑 `start_mambo_server.ps1`，看它输出的报错；
服务窗口必须保持开着（或勾选设置里的「自动拉起」并填好启动命令）。

**首句特别慢**：曼波首次合成要加载 g2pw + CUDA kernel（实测约 90 秒）。
应用启动后会在后台预热一句，等 30–60 秒再点朗读即可。

**换电脑后书架空了**：书架存在 `%APPDATA%`，拷 `VoiceRead` 目录过去即可迁移；
原书文件的路径变了的话，需要重新导入。
