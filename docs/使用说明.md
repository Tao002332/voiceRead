# 使用说明

## 1. 导入小说

- 点左侧「导入 TXT」或「导入 EPUB」，也可以直接把文件拖进窗口
- TXT 自动识别 UTF-8 / GBK / GB18030 / Big5 / UTF-16
- EPUB 按 spine 顺序解析，章节标题取各级标题或文件名
- 「移除」只删书架记录和进度，不动原文件；「从头读」清空该书进度

## 2. 开始朗读

1. 选中一本书 → 自动恢复到上次读到的地方
2. 点「▶ 朗读」
3. 第一次朗读某句会先合成（状态栏显示「合成中…」），之后同一句走缓存，秒开

播放中：
- 点正文任意一句 → 从该句开始读
- 上方下拉框换章
- 「上一句 / 下一句 / 上一章 / 下一章」跳转
- 语速滑块拖动即时生效（会重新合成当前句）

## 3. 悬浮字幕

- 默认出现在屏幕底部居中，鼠标拖动可换位置（自动记住）
- **左键点某一行**：只做标记。**播放中不打断朗读**——正文里给这一句加下划线，
  朗读位置、悬浮字幕都不变；暂停时才把阅读位置移过去
- **右键点某一行**：弹菜单 →`▶ 从这一句开始朗读` / `⏵ 从本段开头朗读` / `复制这一句`；
  选择朗读后，悬浮字幕才开始显示这一句
- 底栏按钮：`⇤` 上一章、`⏮` 上一句、`▶/⏸` 播放暂停、`⏭` 下一句、`⇥` 下一章、`✕` 隐藏字幕
- 滚轮调语速，单击字幕暂停/继续，双击打开主窗口
- 右键菜单：鼠标穿透、显示上下句、字幕外观、隐藏字幕、退出
- 「鼠标穿透」打开后点不到字幕（适合盖在游戏/视频上），此时只能从托盘或全局热键操作

## 4. 隐藏与恢复

字幕窗一直保留，随时能收起和叫回来：

1. **托盘**：关闭主窗口不退出，只收起主界面，字幕继续显示；托盘图标左键单击恢复主界面
2. **字幕右键** → 「隐藏字幕（入口在托盘图标）」：只收起字幕，朗读不中断
3. **全局热键 `Ctrl+Alt+F`**：随时开关字幕，不用找菜单

字幕窗的位置、字号、配色、透明度都记在设置里，下次启动自动恢复。

## 5. 语音选择

| 引擎 | 特点 | 需要 |
|---|---|---|
| Edge 在线语音 | 免费、音色多、支持语速+音调 | 联网 |
| 曼波本地语音 | 最像人，音色由参考音频决定 | 本机显卡 + GPT-SoVITS 服务 |
| Windows SAPI | 完全离线兜底，机械音 | 无 |

切换：控制栏「语音」下拉框，或设置 → 语音引擎。

## 6. 语速与语调

两层叠加：

1. **基础语速/音调**（设置里）：整本书的统一基调
2. **上下文语调**（自动）：按句子类型微调

实际语速 = 基础语速 × 该句语调系数，实际音调 = 基础音调 + 该句偏移。

语调强度滑块控制第二层的影响幅度，0% 等于关闭自动调节。

## 7. 缓存管理

设置 → 高级与缓存：
- 上限默认 800MB，超出后按最久未使用自动清理
- 「清空缓存」会删掉所有已合成音频（不影响进度）

## 8. 常见问题

**没有声音**：检查系统默认输出设备；QMediaPlayer 用系统默认设备。SAPI 引擎首次初始化可能慢 1–2 秒。

**Edge 合成失败**：多半是网络问题，换 Edge 引擎重试，或临时切到 SAPI；也可以设置里点「试听当前音色」快速验证。

**曼波没反应**：见 `docs/曼波模型部署.md` 的排错表；设置里点「测试连接」会给出具体原因（服务没起 / 参考音频路径错 / 显存不足）。

**字幕挡住别的窗口**：开鼠标穿透，或拖到屏幕顶部。

**进度不对**：点「从头读」重置；换文件路径会被当成新书。
